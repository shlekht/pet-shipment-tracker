Небольшой FastAPI проект для личной практики. Имитация сервиса отслеживания доставок. Больший акцент сделан на инфраструктуре приложения, чем на функционал API.
Стек:
- FastAPI
- SQLAlchemy, postgresql, alembic
- Docker, Docker Compose
- Celery, flower, rabbitmq (broker for celery)
- Redis (cache)
- Pytest (unit tests and integration tests)
- Logging, JSON format, Docker container stdout
- JWT Auth, Cookies
- Async
